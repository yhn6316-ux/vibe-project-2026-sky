- 프롬프트 :
히어로 섹션 및 반응형 구현 요구사항

첨부한 첫 번째 이미지는 데스크탑, 두 번째 이미지는 모바일 디자인 레퍼런스다. 이미지를 분석하여 다음 요구사항에 맞게 구현한다.
실제로 사용된 이미지는 images/used 폴더에 있는 이미지를 사용한다.

1. 공통 및 고정 요소
- 상단 헤더 영역은 화면 상단에 고정(`position: fixed`)하여 스크롤 시에도 항상 노출한다.
- 헤더 내부에는 로고, 메뉴 및 유틸리티 아이콘이 배치된다.
- 데스크탑에서는 화면 오른쪽의 세로형 퀵 메뉴(로그인, Sanrio+ 등)를 고정(`position: fixed`)하여 스크롤과 관계없이 유지한다.
- 고정 요소가 콘텐츠를 가리지 않도록 위치와 `z-index`를 설정한다.

2. 데스크탑 레이아웃 (769px 이상)
- 핑크색 헤더에 중앙 로고, 상단 유틸리티 메뉴, 하단 가로형 카테고리 내비게이션을 배치한다.
- 히어로 영역은 이미지 슬라이드가 가로로 배치되는 캐러셀 구조로 구현한다.
- 중앙 슬라이드가 가장 크게 보이며, 좌우에 이전·다음 슬라이드 일부가 노출되는 형태로 구성한다.
- 좌우 이동 버튼과 하단 페이지 인디케이터를 제공한다.
- 히어로 하단에는 캐릭터 장식 이미지와 중요 공지사항 영역이 배치된다.

3. 모바일 레이아웃 (768px 이하)
- 데스크탑 레이아웃을 단순히 축소하지 말고 모바일 전용 레이아웃으로 재구성한다.
- 상단 헤더는 핑크색 배경을 유지하며, 왼쪽에는 햄버거 메뉴와 로그인, 중앙에는 로고, 오른쪽에는 매장 검색 및 온라인 쇼핑 아이콘을 배치한다.
- 데스크탑의 가로형 카테고리 내비게이션은 숨긴다.
- 히어로 캐러셀은 한 개의 슬라이드가 중심에 노출되도록 변경하고, 좌우에 일부 이미지가 보이는 데스크탑 구조는 적용하지 않는다.
- 슬라이드 이미지 아래에 해당 콘텐츠의 제목 및 설명을 배치한다.
- 좌우 이동 버튼과 하단 페이지 인디케이터는 유지한다.
- 캐릭터 장식 이미지는 모바일 화면에 맞게 크기와 배치를 변경한다.
- 중요 공지사항은 화면 너비에 맞는 세로형 카드 레이아웃으로 변경한다.
- 데스크탑 오른쪽 세로형 퀵 메뉴는 모바일에서 숨긴다.

4. 미디어쿼리 및 구현 방식
- 기본 구조와 스타일은 데스크탑 기준으로 먼저 구현한다.
- 이후 `@media (max-width: 768px)` 미디어쿼리를 사용하여 모바일 레이아웃으로 전환한다.
- 데스크탑과 모바일의 요소 배치, 노출 여부, 크기, 정렬 방식이 달라지는 부분을 구분하여 작성한다.
- 이미지와 콘텐츠는 모바일 화면 너비를 초과하지 않도록 반응형 크기를 적용한다.
- 캐러셀은 데스크탑과 모바일 모두 정상적으로 동작하도록 유지한다.
- 기존 HTML 요소와 클래스 구조를 최대한 재사용하고, 불필요한 중복 마크업은 최소화한다.

### 모바일 전체 메뉴(햄버거 메뉴) 구현 요구사항

첨부한 이미지는 모바일 화면에서 햄버거 버튼 클릭 시 나타나는 전체 메뉴 화면의 레퍼런스다. 다음 동작과 구조를 구현한다.

**1. 메뉴 열기 및 닫기**
- 모바일 헤더 왼쪽의 햄버거 버튼 클릭 시 전체 메뉴 오버레이가 화면 상단에서 아래쪽으로 슬라이딩되며 등장한다.
- 메뉴가 열리면 기존 메인 콘텐츠 위에 전체 메뉴가 표시되도록 구현한다.
- 메뉴 왼쪽 상단에는 X(닫기) 버튼을 배치한다.
- X 버튼 클릭 시 메뉴가 아래쪽에서 위쪽으로 슬라이딩되며 사라진다.
- 등장과 퇴장 애니메이션은 자연스럽고 부드럽게 연결되도록 CSS `transform`과 `transition` 등을 활용한다.
- 애니메이션이 진행되는 동안 메뉴가 갑자기 사라지거나 화면이 깜빡이지 않도록 처리한다.

**2. 전체 메뉴 레이아웃**
- 전체 메뉴는 모바일 화면 전체 너비와 높이를 차지하는 오버레이 형태로 구현한다.
- 배경색은 레퍼런스 이미지의 청록색 계열을 적용한다.
- 상단에는 X 버튼, 로그인 아이콘, 중앙 Sanrio 로고, 오른쪽 매장 검색 및 온라인 쇼핑 아이콘을 배치한다.
- 상단 아래에는 키워드 검색 입력창을 배치한다.
- 검색창 아래에는 상세 검색 안내 문구를 배치한다.
- 캐릭터, 굿즈, 무비, 디지털, 스폿, 뉴스 등 카테고리 메뉴를 세로 목록으로 배치한다.
- 각 카테고리는 아이콘과 텍스트, 오른쪽 방향 아이콘으로 구성하며 항목 사이에는 점선 구분선을 적용한다.
- 카테고리 목록 아래에는 Sanrio+ 소개 배너를 배치한다.
- 하단에는 FOLLOW 문구와 SNS 아이콘, 관련 사이트 링크를 배치한다.

**3. 스크롤 동작**
- 전체 메뉴의 콘텐츠가 화면 높이를 초과할 경우 메뉴 내부에서 세로 스크롤이 가능해야 한다.
- 메뉴가 열린 상태에서는 배경의 메인 페이지가 스크롤되지 않도록 처리한다.
- 상단 헤더 영역은 메뉴 내부 스크롤 중에도 고정되도록 구현한다.
- 하단 FOLLOW 영역은 콘텐츠 흐름에 포함하여 스크롤을 통해 확인할 수 있도록 한다.

**4. 반응형 및 인터랙션**
- 전체 메뉴는 모바일 브레이크포인트인 `768px 이하`에서만 동작하도록 한다.
- 769px 이상의 데스크탑 화면에서는 해당 모바일 전체 메뉴를 노출하지 않는다.
- 메뉴 열기 및 닫기 버튼은 기존 모바일 헤더의 햄버거 버튼과 X 버튼에 연결한다.
- 메뉴가 열린 상태에서는 햄버거 버튼 대신 X 버튼이 표시되도록 한다.
- 메뉴 내부 카테고리와 검색창은 실제 클릭 및 입력이 가능한 인터랙티브 요소로 구현한다.
- 메뉴가 닫힐 때 기존 메인 페이지의 스크롤 위치가 유지되어야 한다.

**5. 구현 시 주의사항**
- 기존 HTML 구조와 CSS 클래스, 헤더 구현을 최대한 재사용한다.
- 전체 메뉴는 별도의 컴포넌트 또는 독립적인 영역으로 구성하여 유지보수가 쉽도록 한다.
- 메뉴 열림 상태는 JavaScript 상태값으로 관리한다.
- 단순히 `display: none/block`으로 전환하지 말고 슬라이딩 애니메이션이 정상적으로 동작하도록 구현한다.
- 모바일 메뉴가 화면 밖으로 밀리거나 하단 콘텐츠가 잘리지 않도록 `100dvh`, `overflow-y: auto` 등을 적절히 활용한다.
