# 작업 이력 및 다음 작업 안내

## 현재 구현 상태

- `index.html`에 산리오 일본어 홈페이지 상단 화면을 구성했다.
  - 고정 핑크 헤더, 데스크톱 카테고리 내비게이션, 모바일 햄버거 메뉴
  - 데스크톱 고정 퀵 메뉴
  - `images/used` 배너 이미지를 사용하는 4장 캐러셀과 이전·다음·페이지 선택 컨트롤
  - 데스크톱 좌우 미리보기, 모바일 단일 슬라이드와 제목·설명
  - 캐릭터 장식 이미지와 중요 공지 카드
- 캐러셀은 이미지·제목·설명을 함께 전환한다. 모바일 햄버거 메뉴는 화면 전체를 덮는 슬라이드형 오버레이로 동작한다.
- `icon-news.svg`의 잘못된 SVG 네임스페이스를 수정해 브라우저에서 아이콘이 표시되도록 했다.
- `Characters` 섹션은 이전 사용자 요청으로 삭제된 상태이며 복원하지 않는다.
- CSS는 tokens → base → layout → components → utilities 순서를 유지한다. 별도 프레임워크나 외부 CDN은 사용하지 않는다.

## 이번 작업 검수

- 브라우저에서 데스크톱과 모바일 레이아웃을 확인했다.
- 769px에서 640px 슬라이드 3장이 보이고, 768px 이하에서는 좌우 슬라이드가 숨겨져 중앙 배너만 모바일 너비에 맞게 보이는 것을 확인했다.
- 브라우저 검사에서 가로 넘침과 로드 실패 이미지가 없음을 확인했다.
- 캐러셀 다음 이동, 현재 페이지 표시, 모바일 메뉴 열기 및 메뉴 링크 선택 후 닫힘을 확인했다.
- 768px 경계에서 데스크톱 3장/각 640px 구조와 모바일 중앙 단일 배너(최대 80vw), 모바일 설명·페이지 표시, 공지 카드 세로 흐름을 각각 확인했다.
- 헤더 로고를 `images/used/logo.svg`로 교체하고 데스크톱·모바일 크기를 확인했다.
- 헤더와 데스크톱 퀵 메뉴의 SVG 아이콘 및 텍스트를 흰색으로 변경했다.
- 캐러셀 좌우 화살표에 `images/used/arrow.svg`와 `images/used/circle.svg`를 적용했다.
- 캐러셀 좌우 원형 버튼 색상을 기본 핑크 토큰(`#f49cc2`)으로 변경했다.
- 캐러셀 좌우 화살표 SVG path에 `#f49cc2`를 직접 지정해 원형 테두리와 함께 분홍색으로 표시한다.
- 데스크톱 캐러셀은 각 슬라이드 너비 640px이며, 1920px 이하에서 중앙 이미지를 뷰포트 중앙에 고정하고 좌우 슬라이드를 화면 경계에서 자른다. 768px 이하의 모바일에서는 좌우 슬라이드를 숨기고 중앙 배너 너비를 뷰포트의 80%로 표시한다.
- 프로젝트에 테스트 스크립트가 없고 `node`, `npm`, `git` 실행 파일을 사용할 수 없어 별도 CLI 테스트는 실행하지 않았다.

## 최신 작업 — 모바일 전체 메뉴 오버레이

- 기존 모바일 헤더의 작은 드롭다운 메뉴를 화면 전체를 덮는 청록색 메뉴 오버레이로 교체했다.
- 오버레이는 상단에서 내려오고 X 또는 Escape로 닫힐 때 위로 올라간다. 메뉴가 열린 동안 페이지 배경을 `inert` 및 고정 처리하고, 닫으면 기존 스크롤 위치와 포커스를 복원한다.
- 메뉴 상단에 닫기·로그인·로고·매장 검색·온라인 쇼핑을 배치하고, 검색 입력, 카테고리 목록, `images/used/sanrio-dt_25.png` Sanrio+ 배너, FOLLOW/SNS/관련 사이트 링크를 구성했다.
- 내부 콘텐츠만 세로 스크롤되며 메뉴 상단은 고정된다. 320px 화면에서 로고와 유틸리티 아이콘이 겹치지 않게 소형 로고 크기를 적용했다. 769px 이상에서는 메뉴를 숨기고 기존 데스크톱 내비게이션을 유지한다.
- 브라우저에서 320px·390px·768px 모바일 및 데스크톱 표시, 전체 화면 배치, 메뉴 내부 스크롤과 footer 접근, 검색 입력, 링크 이동, Escape/X 닫기, 배경 스크롤 잠금 및 복원, 화면 너비 전환 시 닫힘을 확인했다. 메뉴 이미지 로드 실패와 가로 넘침은 없었다.
- 작업 환경에서 `node`, `npm`, `git`을 사용할 수 없어 CLI 테스트 대신 통합 브라우저 검증을 수행했다.

## 최신 수정 — 메뉴 시작 위치 및 색상

- 사용자가 첨부한 고정 헤더 이미지의 핑크(#F49CC2)를 확인하고 모바일 메뉴 배경을 기존 청록 토큰 대신 헤더 색상 토큰으로 통일했다. 본문 메뉴 텍스트는 대비비 5.27:1의 짙은 버건디를 적용했다.
- 메뉴 오버레이 위치를 고정 헤더 높이(72px) 바로 아래로 이동하고, 해당 경계에서 메뉴가 아래로 펼쳐지도록 높이와 translate 시작 위치를 조정했다. 상단 고정 헤더는 오버레이가 덮지 않는다.
- 브라우저에서 320px·390px 화면의 헤더/메뉴 경계와 배경색 일치, 가로 넘침 없음, 내부 메뉴 스크롤을 재확인했다.

## 다음 작업 시 확인할 사항

1. 새 작업 전에 이 이력과 현재 코드를 읽고 기존 구현을 중복 생성하지 않는다.
2. 캐릭터 전용 섹션은 다시 추가하라는 요청이 없으면 복원하지 않는다.
3. 메뉴 링크의 목적지 ID가 실제 페이지에 있는지 확인한다.

## 유지해야 할 프로젝트 규칙

- README가 지정한 CSS 모듈 순서를 유지한다: tokens → base → layout → components → utilities.
- Vanilla HTML/CSS/JavaScript를 사용하며 별도 프레임워크나 CDN을 추가하지 않는다.
- CSS 시각 값은 디자인 토큰으로 관리한다.
- `.outer-box` → `.inner-box` → `.part-box` 레이아웃 계층 및 최대 4단계 구조를 유지한다.
- 시맨틱 HTML, `:focus-visible`, WCAG 대비, 모바일 가로 넘침 없음을 유지한다.
