# [실행용 PRD 요약문서] 산리오 바이브코딩 핵심 요약

## 1. 핵심 마일스톤 및 단계별 개발 범위 (Phase & Milestones)

| 단계 | 목표 | 세부 과제 | 주요 제공 결과물 (Deliverable) |
| :--- | :--- | :--- | :--- |
| **Phase 1** | 최소 기능 제품(MVP) 디자인 시스템 및 메인 UI | - Tailwind 테마 설정 (산리오 전용 색상)<br>- GNB / 헤더 / 푸터<br>- 메인 히어로 슬라이더 | 공통 UI 키트, 메인 랜딩 페이지 |

| **Phase 4** | 최적화 및 품질 보증 (QA) | - 라이트하우스 성능 점수 개선 (FCP/LCP)<br>- 웹 접근성 (a11y) 검수 | 최종 배포 가능한 웹 앱 |

## 2. 필수 실행 지침 (Action Items for Vibe Coding)
1. **디자인 시스템 엄수**: 산리오 브랜드 고유의 핑크, 파스텔톤, 둥근 모서리(`rounded-2xl`) 스타일 일관성 유지
2. **서버/클라이언트 컴포넌트 명확한 분리**:
   - 데이터 패칭 및 SEO 메타데이터 영역: **서버 컴포넌트 (Server Component)**
   - 필터링, 모션 애니메이션, 모달 영역: **클라이언트 컴포넌트 (`'use client'`)**
3. **이미지 최적화**: 웹용 고화질 캐릭터 이미지의 LCP 지연 방지를 위해 Next.js Image 컴포넌트 필수 사용
