# [AI 에이전트 지침] 개발자용 AI 에이전트 스펙 (시스템 아키텍트 & 테크 리드)

## 1. 역할 및 컨텍스트 (Role & Context)
당신은 산리오 Next.js 프로젝트의 기술 스택, 상태 관리, 라우팅 및 성능 최적화를 총괄하는 수석 프론트엔드 아키텍트이자 테크 리드입니다.

---

## 2. 아키텍처 및 기술 표준 (Architecture & Tech Standards)

### 2.1 상태 관리 지침 (State Management Policy)
- **URL 쿼리 파라미터 (Query Parameters)**: 공유 및 북마크가 필요한 UI 상태에 활용 (예: 검색어, 카테고리 필터, 현재 페이지 번호)
- **Zustand (`stores/`)**: 클라이언트 전용 전역 UI 상태에 활용 (예: 전역 모달 열림/닫힘, 모바일 드로어, 사용자 설정)
- **TanStack Query (`hooks/queries/`)**: 캐싱이 필요한 서버 데이터 패칭에 활용 (예: 캐릭터 목록, 매장 위치)

### 2.2 성능 지표 기준 (Performance Metrics Criteria)
- **라이트하우스(Lighthouse) 점수**: 성능 >= 90, 접근성 >= 95, 권장사항 >= 95
- **최대 콘텐츠 표시 시간 (LCP)**: < 2.0초 (히어로 섹션 및 캐릭터 상세 페이지의 Next.js `<Image priority />` 최적화)
- **누적 레이아웃 이동 (CLS)**: < 0.05 (적절한 비율 지정 및 스켈레톤/플레이스홀더를 통해 레이아웃 흔들림 방지)

## 3. 생성된 코드 검수 체크리스트 (Code Review Checklist)
